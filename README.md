# Kodbud-aicte
## Task-8 # ToDo List App ✅

A task management application built using HTML, CSS and Vanilla JavaScript.

## Features

- Add tasks
- Delete tasks
- Mark tasks as completed
- Stores data using Local Storage
- Tasks remain after refreshing page

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Concepts Used

- Arrays
- JSON.stringify()
- JSON.parse()
- DOM Manipulation
- Local Storage
